为什么数量对不上

英文名取自日服／韩服最全的官方列表；国服只上线过其中一部分，台服另有自己的活动图。同一个英文名，各服中文叫法不保证一致。

你那个单机包只会更少

1337 整合包通常只放几十张图，还可能混进私服自制图（后缀 _LB、_Test）。实际清单以本机目录为准。

一、模式总表

Game Modes

人数为常规／上限值，私服可在建房时自行放宽；AI Mission 与 Riot 的人数是硬性锁定，不可随意改。

关于你卡住的那张图

SW_Gallery 就是 GALLERY（画廊），一张歼灭图。建服界面显示资源代号而不是官方名，属正常现象。

这意味着你当时选的是歼灭模式 + 画廊地图，控制台反复刷同一组 Spawn Pos 坐标，就是出生点没被正确分配 —— 先换一张图、把双方人数调平，再试 Initialize Game。

九、查你这台机器到底有哪些图

Local Map Inventory

在 Windows 命令行（cmd）里跑，把实际文件名抓出来，再对照上表认领官方名。

:: 列出整合包里所有地图资源文件
dir /b /s "D:\ava1\ava\AVAGame\Maps\*.upk"

:: 若路径不同，先找游戏根目录
where /r D:\ AVA.exe
dir /b /s "D:\ava1\ava\*.upk" | findstr /i "map"

把输出贴回来，我按上表逐条标注「英文名 + 中文名 + 所属模式」，单独给你一份只属于你这套整合包的地图索引。
